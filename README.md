# Stream Radio Mode

### 숲(SOOP) 라디오 모드 + 멀티뷰(치지직·숲·트위치·유튜브 동시 시청)

[![Chrome Web Store](https://img.shields.io/badge/Chrome_Web_Store-설치하기-4285F4?style=for-the-badge&logo=googlechrome&logoColor=white)](https://chromewebstore.google.com/detail/stream-radio-mode/nomodebfjalibapnnkfmbmempgkgjhpo)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow?style=for-the-badge)](LICENSE)

**영상은 잠깐 꺼두고, 소리만 편하게 듣습니다. 여러 방송은 한 화면에서 봅니다.**

Stream Radio Mode는 숲(SOOP) 라이브 방송과 다시보기(VOD)를 오디오 중심으로 바꿔주는 크롬 확장 프로그램입니다. 라디오 모드, 수면모드, 루팡 모드, 대사 EQ, 채팅/리스트 패널, 단축키를 한 화면에서 쓸 수 있습니다. v1.6.0부터 **멀티뷰**로 치지직·숲·트위치·유튜브 방송을 동시에 볼 수 있습니다.

| 클립보드/선택 해제 | 복사·붙여넣기·텍스트 선택·우클릭 차단을 자동 해제합니다 | SOOP에서 Ctrl+C/V, 드래그 선택, 우클릭이 안 될 때 |
| 상태 진단 배지 | SOOP 변경으로 기능이 깨지면 배지에 `!`로 알려줍니다 | 조용히 고장 나는 걸 막고 싶을 때 |

## 설치하기

### 방법 1. Chrome Web Store에서 설치

1. [Chrome Web Store 설치 페이지](https://chromewebstore.google.com/detail/stream-radio-mode/nomodebfjalibapnnkfmbmempgkgjhpo)를 엽니다.
2. **Chrome에 추가**를 누릅니다.
3. 숲(SOOP) 라이브 방송이나 VOD 페이지를 엽니다.
4. `Alt + R`을 누르거나 플레이어의 헤드폰 버튼을 누르면 라디오 모드가 켜집니다.

Chrome, Edge, Whale, Brave처럼 Chromium 기반 브라우저에서 사용할 수 있습니다.

### 방법 2. 직접 설치

개발자나 최신 릴리즈 ZIP을 직접 확인하고 싶은 경우에만 사용합니다.

1. [최신 ZIP 파일](https://github.com/Hahamin/stream-radio-mode/releases/latest/download/stream-radio-mode.zip)을 내려받고 압축을 풉니다.
2. 브라우저 주소창에 `chrome://extensions`를 입력합니다.
3. 오른쪽 위 **개발자 모드**를 켭니다.
4. **압축 해제된 확장 프로그램을 로드합니다**를 누릅니다.
5. 압축을 푼 폴더를 선택합니다.

## 처음 사용법

### 1. 라디오 모드 켜기

1. 숲(SOOP) 라이브 방송 또는 VOD 페이지를 엽니다.
2. 플레이어에 생긴 헤드폰 버튼을 누르거나 `Alt + R`을 누릅니다.
3. 라디오 모드 화면이 뜨면 영상은 숨겨지고 오디오는 계속 재생됩니다.
4. 다시 보고 싶을 때는 **비디오 모드로 전환** 버튼을 누릅니다.

### 2. 팝업에서 설정하기

브라우저 오른쪽 위 확장 프로그램 아이콘을 누르면 팝업이 열립니다.

- **지원 사이트**: SOOP 지원을 켜거나 끕니다.
- **단축키**: SOOP 페이지에서 단축키 사용 여부와 설명을 확인합니다.

- 즐겨찾기, 좋아요, 채팅 버튼 사용

- **프리셋** 버튼으로 `선명`, `저음컷`, `야간` 순환
- **수면모드** 버튼으로 자동 정지 켜기/끄기
- **루팡 모드** 버튼으로 탭 위장
- **비디오 모드로 전환**으로 원래 화면 복귀

## 멀티뷰

v1.6.0에서 추가된 멀티뷰는 치지직·숲·트위치·유튜브 방송을 한 화면에서 동시에 볼 수 있는 기능입니다.

### 시작하기

1. 확장 프로그램 팝업에서 **📺 멀티뷰** 버튼을 누릅니다.
2. 두 가지 방법으로 스트림을 추가합니다:
   - **🔍 찾아보기**: 치지직/숲 라이브 채널 목록에서 골라 추가
   - **+ 추가**: URL 또는 ID를 직접 입력

### 지원 플랫폼

| 플랫폼 | 입력 방법 | 예시 |
|:---|:---|:---|
| 치지직 | 채널 URL 또는 32자 채널 ID | `chzzk.naver.com/live/abcd1234...` |
| 숲 | 방송 URL 또는 BJ ID | `sooplive.com/bjid` 또는 `bjid` |
| 트위치 | 채널 URL 또는 `t:사용자명` | `twitch.tv/user` 또는 `t:user` |
| 유튜브 | 라이브 URL, `y:영상ID`, 또는 채널 URL(현재 라이브 자동 해석) | `youtube.com/live/...`, `y:abc123`, `youtube.com/@채널/live` |

### 찾아보기 패널

**🔍 찾아보기** 버튼을 누르면 왼쪽에 라이브 채널 목록이 열립니다.

- **치지직/숲** 탭 전환으로 플랫폼별 인기 라이브 방송 목록 확인
- 검색창에 스트리머 이름이나 방송 제목 입력으로 검색
- 채널 카드를 클릭하면 바로 멀티뷰에 추가

### 오디오 믹서

타일에 마우스를 올리면 왼쪽 아래에 볼륨 슬라이더·음소거·솔로(`S`) 버튼이 나타나고, 툴바의 **🎚 믹서**를 누르면 모든 스트림을 한 줄씩 다루는 패널이 아래에 열립니다.

- **스트림별 볼륨/음소거**: 플랫폼 플레이어를 직접 제어하므로 플레이어 안에서 바꾼 값도 슬라이더에 반영됩니다.
- **솔로**: 한 스트림만 소리를 남기고 나머지는 음소거합니다. 다시 누르면 해제됩니다.
- **호버 팔로우**: 켜두면 마우스를 올린 타일만 소리가 납니다.
- **볼륨 기억**: 채널별 볼륨을 저장해 다음에 추가할 때 그대로 복원합니다.
- 브라우저 자동재생 정책으로 소리가 막힌 스트림은 타일에 **소리 꺼짐** 안내가 뜨고, 클릭하면 켜집니다.

| 단축키 | 기능 |
|:---:|:---|
| `1` ~ `9` | 해당 번호 스트림 솔로 / 해제 |
| `0` | 솔로 해제 |
| `M` | 전체 음소거 토글 |
| `H` | 호버 팔로우 토글 |
| `R` | 멀티 라디오 토글 |
| `X` | 믹서 패널 열기/닫기 |

### 멀티 라디오

툴바의 **🎧 라디오**를 누르면 모든 타일의 영상이 가려지고 스트리머 이름과 볼륨 컨트롤만 남습니다. 라디오 모드의 멀티뷰 버전으로, 여러 방송을 소리만으로 동시에 들을 때 씁니다.

- 영상은 가려지기만 하고 계속 수신되므로 데이터 절약 효과는 없습니다.
- 트위치 플레이어는 화면이 가려지면 재생을 멈추는 정책이 있어, 트위치 타일만 작은 미리보기를 남깁니다. 같은 이유로 트위치 타일은 라벨과 컨트롤이 영상 위가 아니라 아래 띠에 항상 표시됩니다.

### 기타 기능

- **레이아웃**: 자동(16:9 최적) / 가로 / 세로 / 포커스 모드 전환
- **전체 음소거**: 모든 스트림 일괄 음소거/해제
- **채팅**: 선택한 스트림의 채팅을 오른쪽 패널에 표시
- **URL 상태 보존**: 추가한 스트림 목록이 URL 해시에 저장되어 새로고침해도 유지
- **치지직 와이드**: 치지직 타일은 사이트 헤더·사이드바·채팅을 빼고 플레이어만 꽉 채웁니다

> **권한 안내**: 멀티뷰를 처음 사용할 때 치지직·숲·트위치·유튜브 도메인 접근 권한과 스크립트 주입 권한을 한 번 요청합니다. 임베드 차단 헤더 해제, 라이브 목록 API 호출, 그리고 볼륨 API가 없는 치지직·숲 플레이어에 오디오 브리지를 넣는 데 쓰이며, 설치 시에는 추가 권한이 표시되지 않습니다.

## 기능 설명

### 라디오 모드

라디오 모드는 확장의 핵심 기능입니다. 영상 화면을 숨기고, 방송 정보와 조작 버튼만 남겨 오디오 중심으로 들을 수 있게 합니다.

라디오 모드에서 보이는 정보:

- 스트리머 프로필, 이름, 방송 제목
- 시청자 수
- 방송 시간 또는 VOD 재생 시간
- 라이브/VOD 상태
- 볼륨, 즐겨찾기, 좋아요, 채팅 버튼
- 대사 EQ, 프리셋, 수면모드, 루팡 모드 버튼

라디오 모드를 끄면 비디오 opacity, 화질, EQ, 채팅/리스트 패널, 스크롤 잠금이 원래 상태로 돌아가도록 설계되어 있습니다.

### 수면모드

수면모드는 방송이나 VOD가 끝났을 때 자동으로 멈춰주는 기능입니다.

라이브 방송에서:

- 스트리머가 방송을 종료해 SOOP이 다시보기 화면으로 넘어가려는 상황을 감지합니다.
- 자동으로 라디오 모드를 해제하고 재생을 멈춥니다.
- 라이브 종료 후 소리가 다시 튀어나오지 않도록 안전하게 mute 처리합니다.
- 가능하면 원래 라이브 URL로 되돌려 자동 VOD 전환 상태를 피합니다.

VOD에서:

- 다시보기가 끝나면 자동으로 재생을 멈춥니다.
- 라디오 오버레이를 닫고 비디오 상태를 복원합니다.

수면모드는 두 곳에서 켜고 끌 수 있습니다.

- 확장 프로그램 팝업의 **수면모드** 토글
- 라디오 모드 화면 안의 **수면모드 ON/OFF** 버튼

### VOD 라디오보드

VOD 페이지에서는 라디오 화면이 다시보기용으로 바뀝니다.

- 현재 재생 시간과 전체 길이를 크게 표시합니다.
- 진행바를 클릭하면 원하는 시간으로 이동합니다.
- 진행바에 마우스를 올리면 해당 구간 썸네일을 확인할 수 있습니다.
- 영상은 숨겨도 재생 상태와 탐색은 계속 조작할 수 있습니다.

### 자동 대역폭 절약

라디오 모드를 켜면 확장은 SOOP 플레이어의 화질 제어 API를 사용해 영상 품질을 낮춥니다.

```
고화질 재생  →  안정적인 저화질/적응형 화질  →  오디오는 유지
```

목표는 화면을 숨기는 것에서 끝나는 게 아니라, 실제로 받아오는 영상 데이터도 줄이는 것입니다. 라디오 모드를 끄면 VOD/라이브 화질 상태를 가능한 한 원래 값으로 복원합니다.

### 대사 중심 EQ

라디오 모드 전용 오디오 보정 기능입니다. Web Audio API를 사용해 말소리 대역을 조금 더 잘 들리게 합니다.

| 프리셋 | 설명 |
|:---|:---|
| 선명 | 가장 무난한 기본 설정입니다 |
| 저음컷 | 저음이 과하거나 먹먹할 때 씁니다 |
| 야간 | 오래 듣거나 밤에 작게 들을 때 자극을 줄입니다 |

EQ가 마음에 들지 않으면 라디오 화면의 **대사 EQ** 버튼을 눌러 바로 끌 수 있습니다.

### 채팅과 리스트 패널

라디오 모드에서도 채팅을 볼 수 있습니다.

- **채팅** 버튼을 누르면 채팅창이 다크 테마로 열립니다.
- 리스트 패널은 왼쪽에 분리되어 추천 방송이나 리스트를 보기 쉽게 보여줍니다.
- 리스트나 채팅 안에서 방송 이동 링크를 눌렀을 때도 라디오 모드가 새 플레이어에 다시 붙도록 처리합니다.

### 클립보드/선택 차단 해제

SOOP은 채팅 입력란에서 붙여넣기(Ctrl+V)를 차단하고, 일부 영역에서 텍스트 복사·선택·우클릭도 막습니다. 이 확장 프로그램을 설치하면 별도 설정 없이 다음이 자동으로 해제됩니다:

- **붙여넣기(Ctrl+V)**: 채팅 입력란에서 정상 동작
- **복사(Ctrl+C)**: 텍스트 선택 후 복사 정상 동작
- **텍스트 선택**: 드래그로 텍스트 선택 가능
- **우클릭 메뉴**: 컨텍스트 메뉴 정상 표시

라디오 모드 사용 여부와 관계없이 SOOP 페이지에 들어가면 바로 적용됩니다.

### 루팡 모드

루팡 모드는 급하게 화면 노출을 줄이고 싶을 때 쓰는 보조 기능입니다.

- 탭 제목을 `Google Docs - 업무 보고서.docx`처럼 바꿉니다.
- 파비콘을 문서 아이콘처럼 바꿉니다.
- 가능한 경우 다른 탭으로 자동 전환합니다.
- 오디오는 계속 유지됩니다.

### 최소화 모드

현재 브라우저 창을 최소화합니다. 라디오 모드와 함께 쓰면 화면은 치우고 소리만 들을 수 있습니다.

### 미디어 키 지원

라디오 모드가 켜지면 브라우저 미디어 세션에 스트리머 이름과 방송 제목이 등록됩니다.

- 키보드 미디어 키(재생/일시정지)와 블루투스 이어폰 버튼으로 제어할 수 있습니다.
- Chrome 미디어 허브(주소창 오른쪽 음표 아이콘)에도 방송 정보가 표시됩니다.

### 상태 진단 배지

SOOP 사이트 구조가 바뀌어 확장 기능 일부가 깨지면, 조용히 고장 난 채 방치되지 않도록 알려줍니다.

- 플레이어 연결·화질 제어 API 등을 주기적으로 점검합니다.
- 문제가 감지되면 확장 아이콘 배지가 빨간 `!`로 바뀌고, 팝업에 원인이 표시됩니다.

## 단축키

페이지 단축키는 SOOP 라이브/VOD 페이지에서만 동작합니다. 팝업에서 단축키 사용 여부를 끌 수 있습니다.

| 단축키 | 기능 | 설명 |
|:---:|:---|:---|
| `Alt + R` | 라디오 모드 전환 | 라디오 모드를 켜거나 비디오 모드로 돌아갑니다 |
| `Alt + B` | 루팡 모드 전환 | 탭 위장과 탭 전환을 켜거나 끕니다 |
| `Alt + M` | 창 최소화 | 현재 브라우저 창을 최소화합니다 |
| `Alt + ↑` | 볼륨 올리기 | 볼륨을 5% 올립니다 |
| `Alt + ↓` | 볼륨 내리기 | 볼륨을 5% 내립니다 |
| `Alt + 0` | 음소거/복원 | 음소거하거나 직전 볼륨으로 복원합니다 |

전역 단축키는 SOOP 탭이 아닌 곳에서도 동작합니다. `chrome://extensions/shortcuts`에서 키를 바꿀 수 있습니다.

| 단축키 | 기능 |
|:---:|:---|
| `Alt + Shift + R` | 라디오 모드 전환 (브라우저 어디서나) |
| `Alt + Shift + B` | 루팡 모드 전환 (브라우저 어디서나) |

## 추천 사용 흐름

### 일하거나 공부하면서 라이브 듣기

1. SOOP 라이브 방송을 엽니다.
2. `Alt + R`로 라디오 모드를 켭니다.
3. 필요하면 **대사 EQ**를 켭니다.
4. 방송 종료 후 자동으로 멈추고 싶으면 **수면모드**를 켭니다.
5. 화면 노출을 줄이고 싶으면 `Alt + B` 또는 **루팡 모드**를 씁니다.

### 자기 전에 VOD 듣기

1. SOOP VOD를 엽니다.
2. `Alt + R`로 VOD 라디오보드를 켭니다.
3. 팝업 또는 오버레이에서 **수면모드**를 켭니다.
4. 진행바로 원하는 구간을 맞춘 뒤 듣습니다.
5. VOD가 끝나면 자동으로 멈춥니다.

### 데이터 사용량 줄이기

1. 라디오 모드를 켭니다.
2. 확장이 자동으로 저화질/적응형 화질을 적용합니다.
3. 다시 영상을 보고 싶을 때 **비디오 모드로 전환**을 누릅니다.

## 문제 해결

**라디오 버튼이 안 보입니다.**

- SOOP 라이브 또는 VOD 페이지인지 확인하세요.
- 페이지를 새로고침해 보세요.
- 팝업에서 **지원 사이트 > 숲(sooplive.com)** 체크가 켜져 있는지 확인하세요.

**단축키가 안 먹습니다.**

- SOOP 페이지가 현재 활성 탭인지 확인하세요.
- 팝업에서 **단축키**가 켜져 있는지 확인하세요.
- 브라우저나 운영체제의 다른 단축키와 충돌할 수 있습니다.

**소리가 안 납니다.**

- `Alt + 0`으로 음소거가 걸려 있는지 확인하세요.
- 라디오 화면의 볼륨 슬라이더를 확인하세요.
- SOOP 플레이어 자체가 음소거인지 확인하세요.

**자동 활성화가 갑자기 안 됩니다.**

- 팝업에서 **자동 활성화** 토글이 켜져 있는지 확인하세요. 확장 업데이트나 브라우저 데이터 정리 과정에서 설정이 초기화될 수 있습니다.
- 방송 시작 전(오프라인)에 열어둔 페이지도 방송이 시작되면 자동으로 적용됩니다 (v1.5.0+).

**확장 아이콘에 빨간 `!` 배지가 표시됩니다.**

SOOP 사이트 변경으로 확장 기능 일부가 정상 동작하지 않는다는 신호입니다. 팝업을 열면 어떤 기능이 문제인지 표시됩니다. 페이지 새로고침으로 해결되지 않으면 이슈로 남겨주세요.

**멀티뷰 타일이 빈 화면이거나 볼륨 슬라이더가 비활성입니다.**

- 사이트 접근 권한을 아직 허용하지 않은 상태입니다. 화면 위쪽의 **권한 허용** 배너나 **+ 추가** 버튼을 눌러 권한을 허용하면 타일이 다시 불러와집니다.
- 치지직/숲 타일은 플레이어 안의 영상 요소를 잡은 뒤에 슬라이더가 켜집니다. 광고가 끝나거나 방송이 시작되면 자동으로 연결됩니다.

**업데이트 후 갑자기 동작하지 않습니다.**

SOOP 실제 DOM과 플레이어 API는 바뀔 수 있습니다. 문제가 재현되면 [GitHub Issues](https://github.com/Hahamin/stream-radio-mode/issues)에 URL, 브라우저, 어떤 버튼을 눌렀는지 남겨주세요.
