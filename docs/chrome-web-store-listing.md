# Chrome Web Store 설명 문안

이 문서는 Chrome Web Store 상세설명을 갱신할 때 그대로 복사해 사용할 수 있는 문안입니다. 스토어 업로드 ZIP에는 자동으로 반영되지 않으므로, Developer Dashboard의 설명/상세설명/홍보 문구를 수정할 때 참고하세요.

## 한 줄 설명

숲(SOOP) 라이브와 VOD를 라디오처럼 듣고, 수면모드/루팡모드/대사 EQ/단축키까지 한 번에 쓰는 오디오 중심 확장 프로그램입니다.

## 짧은 설명

Stream Radio Mode는 숲(SOOP) 라이브 방송과 다시보기(VOD)를 오디오 중심으로 바꿔주는 크롬 확장 프로그램입니다. 영상은 숨기고 소리는 유지하며, 자동 저화질 전환으로 대역폭을 줄이고, 방송이나 VOD가 끝나면 수면모드로 자동 정지할 수 있습니다.

## 상세 설명

Stream Radio Mode는 숲(SOOP)을 라디오처럼 듣고 싶은 사람을 위한 크롬 확장 프로그램입니다.

라이브 방송이나 VOD 페이지에서 `Alt + R`을 누르거나 플레이어의 헤드폰 버튼을 클릭하면 라디오 모드가 켜집니다. 영상은 숨겨지고 오디오는 계속 재생되며, 라디오 전용 화면에서 볼륨, 채팅, 좋아요, 즐겨찾기, 대사 EQ, 수면모드, 루팡모드를 바로 조작할 수 있습니다.

주요 기능:

- 라디오 모드: 영상 화면을 숨기고 소리만 편하게 듣기
- 수면모드: 라이브 방송 종료 또는 VOD 종료 시 자동 정지
- VOD 라디오보드: 현재 시간, 전체 길이, 진행바 중심으로 다시보기 듣기
- 자동 대역폭 절약: 라디오 모드에서 안정적인 저화질/적응형 화질로 전환
- 대사 중심 EQ: 말소리가 더 잘 들리도록 `선명`, `저음컷`, `야간` 프리셋 제공
- 채팅/리스트 패널: 라디오 모드에서도 채팅과 추천 리스트 확인
- 루팡 모드: 탭 제목과 파비콘을 문서처럼 위장하고 다른 탭으로 전환
- 최소화 모드: 현재 브라우저 창을 최소화해 화면은 치우고 오디오만 유지
- 단축키: 라디오 모드, 루팡 모드, 최소화, 볼륨 조절, 음소거를 키보드로 조작

사용 방법:

1. 숲(SOOP) 라이브 방송 또는 VOD 페이지를 엽니다.
2. 플레이어의 헤드폰 버튼을 클릭하거나 `Alt + R`을 누릅니다.
3. 라디오 화면에서 볼륨, 채팅, 대사 EQ, 수면모드 등을 조절합니다.
4. 다시 영상을 보고 싶으면 **비디오 모드로 전환** 버튼을 누릅니다.

수면모드 사용 방법:

1. 확장 프로그램 팝업을 엽니다.
2. **수면모드**를 켭니다.
3. 또는 라디오 모드 화면 안의 **수면모드 ON/OFF** 버튼으로 바로 켭니다.
4. 라이브 방송이나 VOD가 끝나면 자동으로 멈춥니다.

단축키:

- `Alt + R`: 라디오 모드 켜기/끄기
- `Alt + B`: 루팡 모드 켜기/끄기
- `Alt + M`: 현재 창 최소화
- `Alt + ↑`: 볼륨 5% 올리기
- `Alt + ↓`: 볼륨 5% 내리기
- `Alt + 0`: 음소거 또는 직전 볼륨 복원

권한 안내:

- `storage`: 자동 활성화, 수면모드, 단축키 설정을 저장합니다.
- `activeTab`, `tabs`: 현재 SOOP 탭에서 라디오 모드/루팡 모드/최소화 기능을 실행합니다.

개인정보:

이 확장 프로그램은 별도 서버로 개인정보를 전송하지 않습니다. 기능은 브라우저 안에서 SOOP 페이지와 확장 프로그램 저장소를 사용해 동작합니다.
